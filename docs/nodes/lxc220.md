# lxc220 - Calibre-Web

Runs Calibre-Web over the e-book library on vm102, plus the timer that imports new books into it.

- Tag: `tag:tier1`

## Resources

- CTID 220, hostname `calibreweb`, Debian 12, unprivileged, nesting on
- 2 cores, 1024 MB RAM, 512 MB swap, 8 GB root disk on `local-lvm`
- Onboot, startup order 5
- Kernel TUN for Tailscale ([DD-13](../decisions/design-decisions.md#dd-13))

## Services

- Calibre-Web, Docker Compose in `/srv/calibreweb`, source `docker/calibre-web/docker-compose.yml`
  (image version there), on `127.0.0.1:8083`
- `calibre-import.timer` - imports settled files from `/books-rw/_import` with `calibredb`, working
  on a local copy of `metadata.db` because SQLite locking fails on CIFS
  ([Calibre-Web](../services/calibre-web.md#auto-import),
  [decision](../decisions/calibre-cifs-sqlite-import.md))

## Storage

- `mp0`: `/mnt/smb/books` -> `/books` - the library, read-only, used by the container
- `mp1`: `/mnt/aux-disk/calibreweb` -> `/var/lib/calibreweb` - local state on the aux-disk
  ([KE-13](../platform/known-errors.md#ke-13))
- `mp2`: `/mnt/smb/books-rw` -> `/books-rw` - the same share read-write, used only by the import job

## Access Model

- Calibre-Web binds loopback and is published through `tailscale serve` on 443:
  `https://calibreweb.<tailnet-id>.ts.net` ([decision](../decisions/loopback-tailscale-serve.md)).
- `lan_guard` drops new inbound LAN connections; sshd binds the Tailscale address.
- Grants are in [tailscale-acl.md](../platform/tailscale-acl.md): admin workstations, the client
  notebook, the e-book reader and the monitoring probe.

## Configuration Management

Applied from lxc250. Node-specific roles:

- `calibre_importer` - installs `calibre`, the import script and its timer
- `tailscale_boot_gate`, `ssh_hardening` - sshd pinned to the Tailscale address
- Group `docker`: `docker_compose_update` (stack listed in `host_vars/lxc220.yml`),
  `docker_boot_retry` and `docker_mount_ordering` (both inactive on this node)

Guest baseline: `apt_metrics`, `journald`, `lan_guard`, `listener_metrics`, `node_exporter`,
`nft_guard` (no ports here), `nsswitch`, `systemd_hygiene`, `timezone`, and the `apt-upgrade.yml`
playbook. See [Ansible](../platform/ansible.md).

## Failure Impact

- No web access to the library. Library files on vm102 are unaffected.
- Files dropped into `/books-rw/_import` wait until the node is back.
- The import job fails when `/books-rw` is not a CIFS mount; it does not skip, so a missing
  mount raises `SystemdUnitFailed` ([KE-15](../platform/known-errors.md#ke-15)).
- Recovery: restore the guest backup or recreate the container and redeploy the stack.
